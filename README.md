# hsscodes.github.io

Personal website of Henrique J. Santos, doctoral researcher in neuroscience at the University of Coimbra.

Live at https://hsscodes.github.io

Fig. 1 is an hSyn::GFP neuron from a human brain organoid, reconstructed from confocal z-stacks and rendered in the browser with three.js. The model is in `assets/neuron.bin`.
